# Ayobami Games Portfolio

A responsive React/Vite portfolio website for game development work, including gameplay programming, technical art, project video previews, popup live demos, a process section, dark/light mode, and downloadable resume.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL Vite gives you, usually:

```txt
http://localhost:5173/
```

## Build for deployment

```bash
npm run build
```

## Deploy

You can deploy this project to Vercel, Netlify, or any static hosting provider that supports Vite.
